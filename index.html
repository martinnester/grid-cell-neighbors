Grid-Cell Neighborhoods

This is a demo of Martin Nester's submission for General Atomics' take home coding challenge.

How to Use

You can navigate to all the examples in the links below. In each one the grid will be rendered with positive values as green, zero as orange, and negative as red. The "effected" or "counted" cells will be lighter colored, and you can see the count in the top left. Also in the top left of each example you can change parameters to the algorithm, or select a new value that will be used to update the grid when you click on cells. When viewing the grid you can pan/zoom/scroll, try holding down the shift or control key while scrolling.
